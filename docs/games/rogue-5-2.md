# Rogue 5.2

Released **4/11/1982**. Developed for VAX 11/780 and PDP 11/70 minicomputers
running BSD Unix.

## Restoration source material

### Binary releases

Extracted from BSD/Unix 4.1c.2 ([rogue5.2-bsd4.1c.2.tar](http://rogue.rogueforge.net/files/rogue5.2/rogue5.2-bsd4.1c.2.tar),
4/4/83) — original location: <http://www.mckusick.com/csrg/>
[Disc 1, directory 4.1c.2]:

```
-rw-r--r--  1614 1983-02-12 13:14 4.1c.2/usr/man/man6/rogue.6
-rwsr-xr-x 90112 1982-06-08 10:35 4.1c.2/usr/games/rogue
-rw-r--r-- 22021 1982-07-20 11:32 4.1c.2/usr/doc/rogue
```

**Rogue 5.2 CMU (rogomatic)** — [rogue53.tar.Z](http://rogue.rogueforge.net/files/rogue5.2/rogue53.tar.Z),
2/16/86. Original location: `http://robot-club.com/lti/rogue53.tar.Z`.
Despite the archive's name, this is a binary distribution of Rogue 5.2 with
some supporting files for Rog-O-Matic that may have been intended for
Rogue 5.3. Likely how Rogue 5.2 was distributed: it includes the parts for
customizing it to a site and building the final executable.

### Source releases

- **Rogue 5.2 NMT** — [rog52-nmt.tar](http://rogue.rogueforge.net/files/rogue5.2/rog52-nmt.tar),
  9/20/93. Provided by Aydin Edguer.
- **Rogue 5.2** — [rogue52.tar](http://rogue.rogueforge.net/files/rogue5.2/rogue52.tar),
  10/11/99. The original archive's dates are lost; this reconstruction
  reflects what was there. Originally obtained from the anonymous FTP site
  at the now-defunct `ftp://uxc.cso.uiuc.edu/games/rogue` in the very early
  1990s — likely a relatively unmodified source.
