# UltraRogue 1.0.7

UltraRogue was developed by **Herb Chong between 1985 and 1986**. Mostly
distributed in binary form; later an unofficial archive was commonly
available (v1.0.3, 8/13/1986).

UltraRogue is based on Rogue 3.6 and an early version of Advanced Rogue.
Herb Chong provided the source code in 1992 and allowed it to be updated
to compile on modern systems — the first restoration this project ever
undertook. Updated to ANSI C; new code written to save and restore the
game state. Herb and I fiddled with it on and off between 1992–1995, and
I picked it up again when the SourceForge project began in 2000.

This is a **semi-active version** of Rogue rather than a pure restoration.
Changes to gameplay and other cosmetic changes have occurred and will
continue to occur.

## Surviving versions

UltraRogue's own 1993 guide gives its pedigree: from Rogue 3.6 by way of
Advanced Rogue to "PreUltraRogue" (17 December 1984), UltraRogue 0.00
(15 January 1985), 1.02 (13 August 1985), 1.03 (13 January 1987) and 2.00
(1 October 1993). Copies of these survive:

| Version | Date in the source | Notes |
|---|---|---|
| 1.02 Beta | "Dr. C and Ivan were here 5/19/85" | The source, 1986–87 file dates |
| 1.02.1 gamma | July 1990 | "Tall Brian SCO release": a 386 SCO binary and its source |
| 1.03 Alpha | 13 August 1986 | |
| 1.03 | "Jeffro was here 10/15/87" | A later 1.03, probably from MIT |
| 1.04 | 24 October 1992 | "1.04UX" |
| 2.00a | September 1993 | With a portable save-file format, a history file and RCS |
| 2.10 | October 1995 | With its SCCS history; the last of Herb Chong's versions to survive |

When the project put UltraRogue into its repository in April 2000, it
numbered the 1993 and 1995 versions "1.05 Alpha (9/01/93)" and "1.06 Alpha
(10/01/95)"; 1.0.7 (2005) follows from those.

### February 7, 2005 — UltraRogue 1.0.7

First re-release of UltraRogue v1.0.7. UltraRogue was developed between
