# Timeline

A rough chronological view of when each version surfaced and when it was
restored.

## Original development

| Year     | Event                                                   |
|----------|---------------------------------------------------------|
| 1980     | Rogue prototyped (Toy, Wichman) at UCSC                 |
| 1981     | Rogue 3.6 released; reaches BSD distribution            |
| 1982     | Rogue 5.2 released                                      |
| 1982–83  | Super-Rogue developed at AT&T Bell Labs (Kindelberger)  |
| 1984–86  | Advanced Rogue 5.x → 7.7 at AT&T Bell Labs              |
| 1985     | Rogue 5.4 released; basis of most modern ports          |
| 1985–86  | UltraRogue developed by Herb Chong                      |
| 1985     | Rog-O-Matic XIV from CMU                                |
| 1989–92  | XRogue developed for AT&T UNIX PC (Pietkivitch)         |

## Restoration era

| Year   | Event                                                     |
|--------|-----------------------------------------------------------|
| 1992   | Herb Chong releases UltraRogue source; first restoration  |
| 1996   | Robert Pietkivitch sends XRogue source                    |
| 2000   | SourceForge project `group_id=4895` registered            |
| 2002   | Robert Pietkivitch passes away                            |
| 2004   | Kindelberger provides Super-Rogue 9.0 source              |
| 2004   | RogueForge.net site (CMS Made Simple) goes live           |
| 2005   | First Super-Rogue 9.0-1 release; UltraRogue 1.0.7 release |
| 2006   | Advanced Rogue 5.8.2 and 7.7.1 releases                   |
| 2013   | Ken Arnold's Rogue 5.4 updated on SourceForge             |
| 2026   | Migration to GitHub — `github.com/rogueforge/...`         |
