# Other Rogue resources

## Playing

**[Retro Rogue Collection](https://github.com/mikeyk730/Rogue-Collection)**,
by Mike Kaminski. It plays six versions in one program: PC Rogue 1.48 and
1.1, and Unix Rogue 5.4.2, 5.3 (the New Mexico Tech version), 5.2.1 and
3.6.3, the Unix ones from this project's earlier releases. It can show the
game as text, as tiles, or on an imitation CRT screen, and it records every
move, so a saved game can be replayed. Since version 3.1.0 it can also let
Rog-O-Matic play.

- [Downloads](https://github.com/mikeyk730/Rogue-Collection/releases)
- [How to play it](https://github.com/mikeyk730/Rogue-Collection/blob/master/docs/readme.md):
  controls, wizard mode and options
- [The versions compared](https://github.com/mikeyk730/Rogue-Collection/blob/master/docs/versions.md):
  how the six versions differ in monsters, items and rules, including the
  changes between PC Rogue 1.1 and 1.48

**[Roguelike Gallery](https://rlgallery.org/)**. Play Rogue 3.6, 5.2 and
5.4, Super-Rogue, Advanced Rogue 5.8 and 7.7, XRogue and UltraRogue in a
web browser or over SSH, with high scores and recent games shared by all
its players. Its versions, the Early Roguelike Collection, began from this
project's earlier releases and were fixed up to run on modern systems.

- [Play](https://rlgallery.org/)
- [Source code](https://rlgallery.org/download.html), release 2021.03

## Source archives

- [The Unix Heritage Society](https://www.tuhs.org/Archive/Distributions/UCB/):
  the Berkeley distributions, with the copies of Rogue that came with them.
- Kirk McKusick's [CSRG Archive](http://www.mckusick.com/csrg/): the
  Berkeley CSRG's own source, on CD-ROM.
