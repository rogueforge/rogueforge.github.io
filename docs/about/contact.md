# Contact

Project email: **`nkissebe+yendor@gmail.com`**.

If you have:

- A rescued tape, floppy, or hard-disk image containing a Rogue family
  version we don't already have;
- First-hand recollection from the original authors that should be
  recorded;
- A correction to one of the restorations;
- A patch or a port to a system we don't currently support;

— please get in touch.

For bug reports and patches against a specific game's source code, please
open an issue or pull request against the appropriate repository under
[github.com/rogueforge](https://github.com/rogueforge).
